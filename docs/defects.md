# Дефекты и регрессии

## D1 — граничное значение срока (исправлено при реализации)

Риск, выявленный при проверке правила: условие `dueAt <= now` ошибочно помечает заявку просроченной в момент наступления срока. Шаги: создать NEW с dueAt=2026-01-01T12:00:00Z, установить Clock на тот же Instant, проверить isOverdue. Ожидается false (по ТЗ срок должен истечь). При ошибочном сравнении получается true. Корректная реализация `dueAt.isBefore(now)`. Регрессионный тест: BusinessTest.exactDueIsNotOverdueRegression. Для доказательства дефекта выполняется временная мутация сравнения, запуск регрессии с ожидаемым падением, затем восстановление и повторный успешный запуск; фактический результат фиксируется в evidence.md.

## E1 — ограничения локальной среды

Docker CLI установлен, но первоначально pipe docker_engine недоступен. Это препятствие среды, не дефект приложения. Интеграционные и контейнерные проверки не должны быть заявлены успешными до доступного движка. Подробности фактического запуска — evidence.md.

## D2 — Testcontainers 1.21.3 несовместим с Docker Engine 29 (исправлено и проверено)

Шаги воспроизведения: установить Docker Engine 29.8.2, запустить `gradlew integrationTest` с Testcontainers 1.21.3. Результат: `initializationError`, NpipeSocketClientProviderStrategy получает HTTP 400, PostgreSQL-контейнер не создаётся. Ожидание: контейнер запускается, выполняются REST-тесты.

Причина: старая версия клиентского Docker API. Исправление: Testcontainers и его BOM зафиксированы на 1.21.4 через `testcontainers.version`; приложение и БД не меняются. Источник исправления: https://github.com/testcontainers/testcontainers-java/releases/tag/1.21.4 . Регрессионная проверка — полный integrationTest на установленном Docker 29. 24 октября 2026 г. все 10 интеграционных/сквозных проверок прошли на Docker 29.8.2; результат записан в evidence.md.
